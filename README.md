# ألعاب العقل — Kids Brain Games (Native)

تطبيق تعليمي أصلي (iOS / Android) للأطفال من ٣ إلى ٩ سنوات، أُعيدت كتابته من الصفر بدل نسخة Base44 (صفحة ويب PWA).
**React Native + Expo + TypeScript** — واجهة أصلية، يعمل بالكامل دون إنترنت، بلا تسجيل دخول، بلا إعلانات، بلا تتبع.

- ٢١ لعبة/نشاط، كل لعبة تتدرج في الصعوبة إلى ما لا نهاية.
- لا خسارة ولا رسائل سلبية: الخطأ يبهت الخيار، وبعد محاولتين يُضاء الجواب الصحيح كتلميح لطيف.
- نجوم، نقاط، ١٥ ملصقًا، ١٥ إنجازًا تفتح صفحات تلوين وزينة، وشخصية (ولد أو بنت) تُفتح ملابسها وإكسسواراتها بالنقاط.
- عدة أطفال على نفس الجهاز (ملف لكل طفل)، وإعدادات الأهل خلف بوابة أبوية.

## التشغيل

```bash
npm install
npm run start:go     # للتجربة السريعة في تطبيق Expo Go على الجوال
npm start            # مع development build (eas build --profile development)
npm test             # اختبارات منطق الألعاب (Jest)
npm run typecheck
npm run lint
```

بناء نسخة حقيقية للأجهزة/المتاجر (بدون Xcode أو Android Studio محليًا):

```bash
npx eas-cli@latest build --profile preview --platform android   # APK للتجربة
npx eas-cli@latest build --profile production --platform all    # للمتاجر
npx eas-cli@latest submit --platform ios|android
```

> مجلدا `ios/` و`android/` يُولَّدان تلقائيًا (Continuous Native Generation) — لا تعدّلهما يدويًا؛ كل الإعدادات في `app.json`.

## البنية

```
src/
  domain/                 ← منطق نقي (TypeScript فقط، بلا React) — مُختبر بالكامل
    engine/session.ts     ← آلة الحالة الوحيدة لكل الألعاب: جولات → مستوى مكتمل → التالي/إعادة
    engine/difficulty.ts  ← مضاعف الصعوبة (٠٫٧ / ١ / ١٫٥) يُطبَّق على كل الألعاب
    games/choiceGames.ts  ← مولّدات ألعاب الاختيار من متعدد (٨ ألعاب)
    games/boardGames.ts   ← منطق ألعاب اللوحة (أشكال، ذاكرة، كلمات، ترتيب، متاهة DFS، أرقام، ألوان)
    games/ticTacToe.ts    ← Minimax + عشوائية حسب الصعوبة
    games/newGames.ts     ← السوق الصغير، ما الذي تغيّر؟، المرآة، فرز النفايات
    games/catalog.ts      ← بيانات كل لعبة (العنوان، العمر، المهارة، الجولات، النقاط)
    content/              ← الحروف العربية، الكلمات، الفواكه، الأعلام، الأشكال، صفحات التلوين (SVG)
    rewards/              ← الملصقات، الإنجازات وما تفتحه، أجزاء الأفاتار
    progress.ts           ← ملف الطفل وقواعد تحديثه (نجوم، نقاط، سلاسل، نشاط يومي)
  data/
    progressStore.ts      ← Zustand + persist — مصدر الحقيقة الوحيد
    storage.ts            ← SQLite key-value على الجهاز (expo-sqlite/kv-store)، قراءة متزامنة
  audio/
    sfx.ts                ← مؤثرات صوتية داخل الحزمة + اهتزاز (expo-audio, expo-haptics)
    speech.ts             ← نطق: تسجيل صوتي إن وُجد، وإلا expo-speech كاحتياط
  ui/
    components/GameShell.tsx   ← الغلاف الموحد: رأس، نقاط الجولات، حفظ، شاشة النجاح
    components/ChoiceGame.tsx  ← لوحة اختيار من متعدد عامة (تلميح، مؤقت اختياري)
    games/                     ← واجهة كل لعبة + registry.tsx
    coloring/                  ← لوحة التلوين (تعبئة، فرشاة، ملصقات، تراجع) + المعرض
    games/room, waste, market  ← رسومات متجهة: الغرفة، الحاويات، العملات والأوراق النقدية
    components/Backdrop.tsx    ← المشهد الخلفي (سماء وتلال نهارًا، نجوم وقمر ليلًا)
  app/                    ← الشاشات (expo-router): الرئيسية، الإحصائيات، الرسم، اللعبة، الإعدادات…
```

### إضافة لعبة جديدة

1. مولّد جولة في `src/domain/games/` — دالة نقية `(level, settings, rng) => round` مع اختبار.
2. سطر في `src/domain/games/catalog.ts` (العنوان، العمر، الجولات، النقاط).
3. سطر في `src/ui/games/registry.tsx`. للعبة اختيار من متعدد يكفي `<ChoiceGame generate={…} renderPrompt={…} renderOption={…} />`.

المحرك يتولى المستويات والنقاط والتلميح والحفظ والاحتفال تلقائيًا.

## ما الجديد في هذه النسخة

- **بومي** (البومة المرشدة) تشرح كل لعبة بالصوت في أول زيارة، وزر «؟» يعيد الشرح.
- **١–٣ نجوم** لكل مستوى (إكمال، بلا تلميح، بلا خطأ).
- **صعوبة تتكيّف تلقائيًا:** قفزة بعد مستويين مثاليين، وإعادة بعد مستويين صعبين (يمكن إيقافها).
- **لعبة اليوم** بنقاط مضاعفة، و«تابع اللعب» في الرئيسية.
- **منهج الحروف العربية:** الأشكال المختلفة أولًا، والحروف المتشابهة بالنقاط لاحقًا. وCapital ↔ small تبدأ بالأزواج مختلفة الشكل.
- **كشف الصوت العربي:** تنبيه للأهل مع خطوات التثبيت، وعرض الكلمة مكتوبة عند غياب الصوت.
- **للأهل:** تقرير أسبوعي (وقت اللعب، الأيام، المستويات، ما يتقنه وما يحتاج تدريبًا) وحدّ يومي للعب.
- **خط Tajawal** للأطفال (ترخيص SIL OFL) مضمّن في التطبيق.
- **CI:** فحص الأنواع والتنسيق والاختبارات وبناء أندرويد مع كل دفع (`.github/workflows/ci.yml`).

## الترجمة واللغات

كل نصوص الواجهة في `src/i18n/` وليست داخل الكود:

- `ar.ts`: القاموس العربي، وهو المرجع.
- `en.ts`: الإنجليزية. نوعه `Shape<Dict>`، فأي مفتاح ناقص أو زائد خطأ في فحص الأنواع.
- `core.ts`: تعبئة `{name}`، وصيغ الجمع العربية (zero/one/two/few/many/other).
- `index.ts`: الدالة `useI18n()` التي تُرجع `t('home.myStickers', { count })`، و`lang`، و`dir`، و`name(item)` لاختيار الاسم من بيانات المحتوى `{ ar, en }`.

**تغيير اللغة:** من إعدادات الأهل (العربية / English / حسب الجهاز). اتجاه الواجهة يتبدّل فورًا (من اليمين لليسار أو العكس) دون إعادة تشغيل.

**إضافة نص جديد:** أضف المفتاح في `ar.ts` ثم في `en.ts`، واستخدم `t('section.key')`.

**إضافة لغة:** أنشئ `fr.ts` بنوع `Shape<Dict>`، وأضفها إلى `Lang` و`DICTS`. إن كانت تُكتب من اليمين لليسار فأضفها إلى `RTL_LANGS`.

**اختبارات الترجمة:**
- تطابق المفاتيح والمتغيرات بين اللغات.
- صيغ الجمع.
- اختبار يمنع كتابة نص عربي داخل الشاشات (`noHardcodedText.test.ts`).

محتوى التعليم العربي (الحروف وكلماتها) يبقى عربيًا في كل اللغات.

## الألعاب

| اللعبة | العمر | التدرج |
|---|---|---|
| مطابقة الأشكال | ٣–٥ | ٣ → ٨ أشكال، ثم نفس الشكل بألوان مختلفة |
| الفواكه والخضروات | ٣–٥ | عربي ثم إنجليزي، مشتتات من نفس النوع، ٥ → ١٢ جولة |
| لعبة الذاكرة | ٣–٥ | ٣ → ١٢ زوجًا، نقاط أكثر لمحاولات أقل |
| الحروف العربية | ٣–٥ | ٣ أوضاع: استمع، الكلمة الأولى، استكشف؛ ٧ → ٢٨ حرفًا |
| التلوين الإبداعي | ٣–٥ | ١٠ صفحات، ٧ منها تُفتح بالإنجازات |
| فرز النفايات | ٣–٥ | سحب الشيء إلى حاوية بعجلات (ورق، بلاستيك، طعام، مخلفات أخرى)؛ حاويتان ← ٤ |
| تعلم الحروف (صوت ← حرف) | ٥–٧ | A–H ← A–P ← الأبجدية؛ حروف تركيز من الإعدادات |
| Capital ↔ small | ٥–٧ | ٣ → ٦ أزواج |
| ترتيب الأرقام | ٥–٧ | ٣ → ١٠ أرقام حتى ٥٠٠ |
| إكمال الأنماط | ٥–٧ | لون فقط ثم شكل ولون، وحدة ٢ → ٦، طول ٤ → ١٦ |
| تكوين الكلمات | ٥–٧ | ٣ → ٨ حروف، حرف مُضلِّل من المستوى ٦ |
| ما الذي تغيّر؟ | ٥–٧ | غرفة ثلاثية الأبعاد بأغراضها؛ ٣ → ٩ أشياء؛ شيء اختفى ← شيء جديد ← شيئان تبادلا المكان |
| المرآة | ٥–٧ | شبكة ٤ أعمدة → ٨، محور أفقي أو عمودي من المستوى ٦ |
| تعلم الساعة | ٥–٧ | ساعات ← أنصاف ← أرباع ← ٥ دقائق ← أي دقيقة |
| تحدي الرياضيات | ٧–٩ | جمع/طرح/ضرب ونطاق من الإعدادات، مكافأة سرعة (بلا عقاب) |
| السوق الصغير | ٧–٩ | دفع السعر بالضبط (٩ → ٩٩) بعملات وأوراق أكثر، وحساب الباقي من المستوى ٤ |
| أعلام الدول | ٧–٩ | ٧٠ دولة، مشتتات من نفس القارة لاحقًا |
| X O | ٧–٩ | الروبوت يقوى مع المستوى حتى اللعب المثالي |
| المتاهة | ٧–٩ | ٥×٥ → ١٩×١٩، سحب أو أسهم، مكافأة للمسار القصير |
| التركيز (أرقام) | ٧–٩ | ٤ → ٩ أرقام |
| تذكر الألوان | ٧–٩ | ٤ → ٨ ألوان، تسلسل ٣ → ١٢ |

## قرارات تصميمية مقارنة بالنسخة القديمة

| المشكلة في نسخة Base44 | الحل هنا |
|---|---|
| ١٧ صفحة تكرر نفس الحلقة (~٧٠٠٠ سطر) | محرك واحد `session.ts` + `GameShell`؛ كل لعبة = مولّد + واجهة لوحتها فقط |
| مصدران للبيانات (localStorage + UserProgress) | مصدر واحد على الجهاز (SQLite)، بلا خادم |
| PWA غير موثوق على iOS | تطبيق أصلي، أيقونات وشاشة بداية حقيقية |
| أصوات من CDN خارجي | المؤثرات مولّدة داخل الحزمة (`scripts/generate-sfx.mjs`) |
| تسجيل دخول لتطبيق أطفال | لا حساب: اسم وأفاتار فقط، وعدة أطفال على الجهاز |
| مضاعف الصعوبة في لعبتين فقط | يُطبَّق على كل الألعاب عبر `effectiveLevel` |
| لا اختبارات | اختبارات Jest لكل المولّدات والمحرك وقواعد التقدم |
| لوحات محفوظة كـ Base64 | تُحفظ كبيانات متجهة (ألوان + خطوط) وتُعاد رسمها |

## ما تبقّى قبل النشر

- **تسجيل صوتي للحروف العربية وكلماتها** (٢٨ + ٢٨ ملفًا): ضع الملفات في `assets/audio/ar/...` وسجّلها في `RECORDINGS` داخل `src/audio/speech.ts`. حتى ذلك الحين يُستخدم نطق الجهاز.
- **اختبار على أجهزة حقيقية** (iOS وAndroid) — التحقق الحالي تم عبر الاختبارات وبناء حزمة Android ومعاينة الويب.
- **حساب Expo/EAS وحسابات المتاجر**، وتأكيد معرّف الحزمة (`com.alqemah.kidsbrain` حاليًا في `app.json`).
- **رابط سياسة خصوصية** (مطلوب لفئة Kids في App Store وGoogle Play Families).
- اختياري: تصدير اللوحة كصورة PNG ومشاركتها، واجهة لاستيراد تقدم النسخة القديمة (الدالة `importLegacy` جاهزة ومُختبرة).
